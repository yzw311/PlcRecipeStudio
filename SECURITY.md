# Security Policy

## Supported versions

Security fixes target the latest release and the default branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Contact the maintainer through the private security-advisory feature of the GitHub repository and include a reproducible description, affected version, impact, and a safe proof of concept. Do not include real PLC credentials, production connection strings, API keys, or customer data.

The application is intended for authorized automation environments only. Test with mock PLCs and temporary data directories; never test against a production PLC without written authorization.
